# Trump Market Watch

トランプ氏の公開発言・政策発表・公開取引情報と、関連銘柄の市場反応を日本時間（JST）で整理する独立アプリです。

## MVP
- 発言時刻（JST）を最優先で表示
- 原文 / 正確な日本語訳 / 1行要約
- 関連ティッカー
- 情報源
- 発言時株価 / 5分後 / 30分後 / 1時間後 / 終値
- 発言時刻と報道時刻を分離
- 発言時刻が確認できない場合は推測せず「確認できず」
- 公開取引（DISCLOSED BUY / SELL）
- 政策・政府契約（POLICY / CONTRACT）
- 検索・履歴

## Development
```bash
npm install
npm run dev
```

## Notes
本アプリは情報整理ツールです。売買判断を自動で行うものではありません。
